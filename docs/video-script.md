## 【开场】项目介绍

我们本次实习项目是 **PromptCraft — AI 提示词工场**，一个面向 AI 时代的提示词共享社区平台。

**画面：** 主页全貌，展示卡片列表

---

## 【第一部分】需求分析

我们的需求来自一个现实痛点：AI 工具的输出质量高度依赖提示词，但普通用户缺乏编写高质量提示词的能力。因此我们设计了一个**提示词共享社区**，让有经验的用户发布提示词，其他人可以浏览、搜索、复制使用。

系统涉及三类角色：**游客**可以浏览和搜索；**注册用户**可以发布、编辑、点赞；**管理员**拥有全部操作权限。核心功能共 13 项，涵盖用户认证、提示词 CRUD、分类筛选、搜索联想、点赞互动等模块。

**画面：** 快速切换——用例图 → 功能需求表 → 登录流程图

## 【第二部分】技术路线

技术上采用**前后端分离的 B/S 架构**。前端使用 Vue 3 + Composition API，通过 8 个 Composables 模块化管理业务逻辑，包括用户认证、提示词操作、搜索与联想、弹窗、剪贴板、主题切换等。路由使用 Vue Router 4，HTTP 通信使用 Axios。

后端使用 Express 5 搭建 RESTful API，共 12 个接口。数据库采用 better-sqlite3 嵌入式数据库，设计了 users、prompts、user_likes 三张表，通过外键和联合唯一约束维护数据一致性。所有查询使用预编译语句，杜绝 SQL 注入。

认证方面使用 JWT 令牌机制，登录后签发 Token，前端存储到 localStorage，后续请求自动携带。

**画面：** 架构图 → 数据库 E-R 图 → API 接口表 → 登录演示

## 【第三部分】安全设计

安全是本项目的重点。我们实现了五层防护：

第一，JWT 身份认证，前后端双重校验防伪造和越权；第二，参数化查询防 SQL 注入，同时故意保留搜索接口的漏洞版本供课堂攻防演示；第三，Vue 插值自动转义防 XSS；第四，邮箱正则脱敏保护用户隐私；第五，后端基于 IP 的登录速率限制，5 分钟内失败超过 5 次返回 429 拒绝请求，防止暴力破解。
